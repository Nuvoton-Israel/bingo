version 0.0.8
---------------
* Add mask format 'fillField': <mask format='fillField'>0xff</mask> selects the whole field.
	Valid only for the <mask> of an ecc=none field (empty value or 0xff), used with the -mask pass.
	A bare <mask>0xff</mask> on an ecc=none field is unchanged (only the first byte is selected).
	Output is identical to 0.0.7 for all existing Arbel fuse maps.
* Fix build with current g++: use std::ios_base::openmode for the file open mode.

version 0.0.7
---------------
*Add fallback file resolution for XML relative paths:
	Fixes issue where XML files in subdirectories couldn't find relative path files.
	Now tries original path first, then xmlDirectoryPath + relative path as fallback.
* Fix variable name conflict in CmdLineParser
